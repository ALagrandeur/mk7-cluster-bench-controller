🔆 Cluster Wake

Klemmen_Status_01 — simule "ignition+start ON" pour réveiller le cluster (avec hardware Kl.15).
Active aussi automatiquement le System Context Bundle (Airbag_01, ESP_05, ESP_10, ESP_20, TSK_07, LH_EPS_01) à 10 Hz — sans ces heartbeats, le cluster invalide la vitesse après 10s, jette des warnings frein, et ignore les boutons MFA.

0x3C0 XX XX 03 00 CRC + counter MQB auto · 10 Hz
+bundle 0x040, 0x106, 0x116, 0x65D, 0x31E, 0x32A Airbag, ESP_05/10/20, TSK_07, LH_EPS_01 · 10 Hz auto

⚙️ Advanced — boost mapping, formule, MAP/temp réelles UDS

Boost → Temperature mapping

Quand le slider est en mode Boost: la valeur est mappée linéairement sur la plage temp. Permet de "compresser" le boost dans la plage utile du cadran (au-dessus de la zone neutre 80-110°C).

Motor_09 byte 0 formula (cluster reads this)

Le byte 0 envoyé est calculé comme: byte0 = round((temp_C - offset) / scale)
Mapping linéaire r00li par défaut: 50°C → 0x80, 130°C → 0xED, soit scale=0.7339 offset=-43.94.

🅿️ Transmission (MFA gear indicator)

WBA_03 (0x394). byte 1 high nibble = selector: P=0x10, R=0x20, N=0x30, D=0x40, S=0x50, M(manual)=0x60. byte 3 = M-gear (0 pour autres modes).

0x394 XX 1X 00 00 00 04 00 00 P · selector 0x10, m_gear=0 · 20 Hz

🎮 MFA Steering Wheel Buttons

Click le bouton pour envoyer (press + release auto). Chaque bouton a son ID, length, press payload et release payload éditables. Raccourcis clavier: ←↑→↓ + Enter (OK) + Esc (BACK).
⚠️ Prérequis: le cluster ignore MFSW si LH_EPS_01 (steering "alive") n'est pas dans le bundle système. Active Wake en haut → le System Context Bundle se déclenche → MFSW devient acceptable.
💡 Pour identifier les vraies adresses: branche en parallèle voiture, sniffe avec Bus Sniffer en bas pendant que tu presses chaque bouton physique du volant, repère l'ID + le payload qui change, puis édite ici et clique Save buttons.

💡 Dashboard Lights & Indicators

Chaque ligne = un témoin. Click ON pour envoyer le payload "allumé", OFF pour éteindre.
⚠️ Important: les défauts utilisent Kombi_01 (0x30B) qui est en réalité envoyé PAR le cluster, pas vers lui (cf. openpilot ne l'envoie jamais). Donc les bits Kombi_01 ne contrôlent probablement PAS les lampes — ils REPORTENT l'état actuel. Les vraies lampes sont contrôlées par les messages source (ESP_21 pour ABS, etc.). À identifier au cas par cas via Bus Sniffer.
💡 Méthode pour identifier: branche voiture, snapshot dans Bus Sniffer, allume le témoin via VCDS ou en simulant la condition (ouvrir porte, etc.), regarde quel ID/byte a changé.
