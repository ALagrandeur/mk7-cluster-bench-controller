🔆 Cluster Wake

Klemmen_Status_01 — simule "ignition+start ON" pour réveiller le cluster (avec hardware Kl.15).
Active aussi automatiquement le System Context Bundle (Airbag_01, ESP_05, ESP_10, ESP_20, TSK_07, LH_EPS_01) à 10 Hz — sans ces heartbeats, le cluster invalide la vitesse après 10s, jette des warnings frein, et ignore les boutons MFA.

0x3C0 XX XX 03 00 CRC + counter MQB auto · 10 Hz
+bundle 0x040, 0x106, 0x116, 0x65D, 0x31E, 0x32A Airbag, ESP_05/10/20, TSK_07, LH_EPS_01 · 10 Hz auto

⚙️ Advanced — boost mapping, formule, MAP/temp réelles UDS

Boost → Temperature mapping

Quand le slider est en mode Boost: la valeur est mappée linéairement sur la plage temp. Permet de "compresser" le boost dans la plage utile du cadran (au-dessus de la zone neutre 80-110°C).

Motor_09 byte 0 formula (cluster reads this)

Le byte 0 envoyé est calculé comme: byte0 = round((temp_C - offset) / scale)
Mapping linéaire r00li par défaut: 50°C → 0x80, 130°C → 0xED, soit scale=0.7339 offset=-43.94.

🅿️ Transmission (MFA gear indicator)

WBA_03 (0x394). byte 1 high nibble = selector: P=0x10, R=0x20, N=0x30, D=0x40, S=0x50, M(manual)=0x60. byte 3 = M-gear (0 pour autres modes).

0x394 XX 1X 00 00 00 04 00 00 P · selector 0x10, m_gear=0 · 20 Hz
